# FinConsultant Telegram Bot

Telegram-бот уровня "персональный финансовый коуч":

- общается по-человечески и поддерживает пользователя;
- умеет понимать текст и голосовые сообщения;
- автоматически определяет риск-профиль;
- собирает персональный план с понятными рекомендациями;
- формирует PDF-отчет с графиками и деталями портфеля.

В каждом финансовом ответе используется дисклеймер: **«Это не является финансовой рекомендацией».**

## Функции

### Команды
- `/start` — начать сбор данных
- `/help` — справка
- `/plan` — показать персональный план
- `/pdf` — отправить PDF-отчет с графиками
- `/reset` — удалить сохраненные данные

### Что бот делает
- Пошагово собирает:
  - возраст, семейный статус, иждивенцев;
  - доход/расходы/сбережения;
  - активы и долги;
  - финансовые цели (сумма, срок, приоритет).
- Определяет риск-профиль автоматически:
  - по эвристике (возраст, свободный поток, долговая нагрузка, горизонты целей),
  - или через LLM (если задан OpenAI API ключ).
- Генерирует "живые" рекомендации:
  - по бюджету,
  - по дисциплине накоплений,
  - по категориям фондов и структуре портфеля (образовательный формат).
- Создает PDF с графиками:
  - cashflow (доход/расходы/свободный поток),
  - круговая диаграмма аллокации активов.

## Технологии

- Python 3.11+
- `python-telegram-bot`
- SQLite
- OpenAI API (опционально, для "человечного" диалога и voice transcription)
- `reportlab` + `matplotlib` для PDF и графиков

## Установка

```bash
cd /workspace
pip3 install --user -r requirements.txt
```

Если в вашей среде доступен venv:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка `.env`

```bash
cp .env.example .env
```

Пример:

```env
TELEGRAM_BOT_TOKEN=ваш_токен
DATABASE_PATH=data/finbot.sqlite3
LOG_LEVEL=INFO
CONFIG_PATH=config/messages.json
OPENAI_API_KEY=ваш_openai_api_key
OPENAI_MODEL=gpt-4o-mini
```

> `OPENAI_API_KEY` обязателен для распознавания voice и AI-ответов "как человек".
> Без него бот работает, но в более базовом режиме.
> Для voice транскрипции используется отдельная модель `gpt-4o-mini-transcribe`.

## Формулы и подходы

1. Коэффициент сбережения:
```text
Savings Ratio = max(Доход - Расходы, 0) / Доход
```

2. Соотношение долга к доходу:
```text
Debt-to-Income = Общий долг / (Месячный доход * 12)
```

3. Резервный фонд:
- 4 месяца расходов (без иждивенцев),
- 6 месяцев (с иждивенцами).

4. Аллокация:
- база по возрасту: `100 - возраст` в акциях,
- риск-кап: 30% / 50% / 70% (консервативный/умеренный/агрессивный),
- коррекция на горизонт целей,
- итоговая нормализация долей до 100%.

## Ограничения и безопасность

- Бот не дает гарантий доходности.
- Рекомендации по фондам и портфелю — образовательные, не индивидуальный инвестиционный совет.
- В каждом финансовом совете добавляется фраза:
  **«Это не является финансовой рекомендацией».**
