# FinConsultant Telegram Bot

Готовый к развертыванию Telegram-бот на Python, который:

- собирает финансовые данные пользователя через интерактивный диалог;
- анализирует текущую финансовую ситуацию;
- генерирует персонализированный финансовый план;
- выдает рекомендации по бюджету и распределению активов по классам.

> В каждом плане добавляется дисклеймер: **«Это не является финансовой рекомендацией»**.

## Возможности

- Команды:
  - `/start` — запуск опроса и сбор данных
  - `/help` — справка
  - `/plan` — повторная генерация плана по сохраненным данным
  - `/reset` — удаление сохраненных данных пользователя
- Диалог собирает:
  - возраст, семейный статус, иждивенцев;
  - доход, расходы, сбережения;
  - активы (недвижимость, авто, бумаги, крипто);
  - долги (ипотека, потребкредиты, прочее);
  - риск-профиль (консервативный/умеренный/агрессивный);
  - финансовые цели (сумма, горизонт, приоритет).
- Аналитика:
  - коэффициент сбережения;
  - соотношение долга к доходу;
  - целевой размер резервного фонда и дефицит;
  - стратегия достижения целей.
- Распределение активов:
  - акции отечественные;
  - акции иностранные;
  - облигации;
  - недвижимость;
  - денежные средства;
  - альтернативные активы;
  - криптовалюты.

## Установка и запуск

1. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

3. Получите токен у [@BotFather](https://t.me/BotFather) и вставьте в `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен
DATABASE_PATH=data/finbot.sqlite3
LOG_LEVEL=INFO
CONFIG_PATH=config/messages.json
```

4. Запустите бота:

```bash
python main.py
```

## Как работает расчет (кратко)

### 1) Коэффициент сбережения

```text
Savings Ratio = max(Доход - Расходы, 0) / Доход
```

### 2) Соотношение долга к доходу

```text
Debt-to-Income = Общий долг / (Месячный доход * 12)
```

### 3) Резервный фонд

- 4 месяца расходов (если нет иждивенцев)
- 6 месяцев расходов (если есть иждивенцы)

```text
Emergency Fund Target = Месячные расходы * (4 или 6)
Emergency Fund Gap = max(Target - Текущие сбережения, 0)
```

### 4) Распределение активов

Используются:

- правило возраста: `100 - возраст` (базовая доля акций),
- ограничение по риску:
  - консервативный: до 30% агрессивных активов,
  - умеренный: до 50%,
  - агрессивный: до 70%,
- поправки на горизонт целей (короткие цели -> больше кэша и облигаций).

Итоговые проценты нормализуются до 100%.

## Поведение бота

- Общается простым и дружелюбным языком.
- На сообщения не по теме финансового планирования отвечает вежливым отказом и перенаправляет к `/start` или `/plan`.
- Если вопрос узкоспециализированный, бот честно сообщает, что может не знать точный ответ.

## Безопасность и ограничения

- Это обучающий инструмент, не персональный инвестиционный советник.
- Каждый финансовый план содержит дисклеймер:
  - **«Это не является финансовой рекомендацией».**
